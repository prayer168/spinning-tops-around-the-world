# 傾斜旋轉陀螺力學稽核

- 稽核日期：2026-07-29
- 對象：`#top-mechanics-diagram`
- 座標約定：x 向右、y 向上、z 指向紙面外
- 圖示姿態：旋轉軸向左偏離鉛直方向 16°

## 驗證的力學關係

1. 重力在重心 C 向下作用，接觸點 P 為力矩參考點。
2. 力臂向量 r 從 P 指向 C；左傾時 r 的水平分量為負。
3. `τ = r × mg` 的 z 分量為正，與圖中的「⊙ 指向紙面外」一致。
4. 傾角為 0° 時，重心位於接觸點正上方，重力力矩為零。
5. 對近似軸對稱且主要繞對稱軸快速自旋的情況，使用 `L ≈ Iω`。
6. 以 `dL／dt = τ` 說明力矩主要改變角動量方向。
7. `Ω ≈ τ／L` 只作快速、近似穩定進動的定性估計，不宣稱適用於所有晃動與倒下階段。
8. 地面摩擦方向由接觸點的相對滑動決定，圖中不指定固定左右方向。

## 可重現樣本

取質量 0.18 kg、P 到 C 距離 0.12 m、傾角 16°、轉動慣量 0.0008 kg·m²、角速度 120 rad/s：

- 重力力矩量值：約 0.0584 N·m
- 角動量量值：約 0.0960 kg·m²/s
- 快速穩定進動估計：約 0.608 rad/s

## 限制

- 圖為單一瞬間的定性受力圖，箭頭長度不代表數值比例。
- 未解完整 Euler 方程、接觸點微滑動、章動或空氣動力細節。
- 地面支撐力只有在重心鉛直加速度很小時才可近似與重力平衡。
