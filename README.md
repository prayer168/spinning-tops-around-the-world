# 旋轉世界：各國陀螺文化與科學

以陀螺為入口，連結旋轉科學、臺灣童玩與世界文化的繁體中文互動教材。

## 專案狀態

目前版本：`v0.1.0`（專案初始化）

## 預計內容

- 學習任務與學習進度
- 角動量、力矩、進動、摩擦與穩定性的圖解及模擬
- 臺灣常見陀螺、玩法與安全操作
- 日本、韓國、中國、印度、東南亞、墨西哥及歐洲陀螺圖鑑
- 操作排序、圖像判讀挑戰及自主學習資源

## 本機預覽

```powershell
npm run serve
```

開啟 `http://localhost:8080/`。
