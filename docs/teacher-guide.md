# 教師使用說明

## 建議流程（40～50分鐘）

1. 學習任務（5分鐘）：請學生先說出「陀螺為何不會立刻倒下」的原想法。
2. 旋轉科學（12分鐘）：操作三個滑桿，每次只改一個變因並記錄觀察。
3. 臺灣與世界圖鑑（12分鐘）：兩人一組選兩地，比較材料、啟動方式與玩法。
4. 操作安全（8分鐘）：完成六步驟排序；若進行實物操作，先劃定投擲區與等待線。
5. 圖像挑戰（8分鐘）：完成八題後，依解析回看教材。

## 引導問題

- 轉速變慢時，陀螺的軸線發生什麼變化？
- 哪一項證據顯示「旋轉沒有取消重力」？
- 空竹與地面陀螺都旋轉，為什麼仍應分成不同構造？
- 相同科學原理如何在不同文化中形成不同玩法？

## 安全提醒

- 實體木陀螺只在空曠、平坦、有界線的場地操作。
- 一次只讓一組進入投擲區，旁觀者站在等待線後。
- 檢查繩索、陀螺釘與本體裂痕；大型陀螺由成人或熟練者示範。
- 本站圖解不能取代現場教師、教練與產品說明。
