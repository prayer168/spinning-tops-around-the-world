# Image 2.0 圖像生成紀錄

生成日期：2026-07-29  
生成方式：Codex 內建 Image 2.0／`image_gen`，每個資產各自呼叫一次  
共同用途分類：`scientific-educational`；社群圖為 `ads-marketing`

## 共同美術指導

- 溫暖紙張質感的數位水粉／教育博物圖鑑風格。
- 松綠、琥珀金、磚紅、原木與米白色。
- 教學寫實、自然光、乾淨構圖、物件完整。
- 排除文字、字母、數字、國旗、品牌、標誌與浮水印。
- 文化圖鑑強調材料和輪廓差異，不把亞洲陀螺畫成同一外形。
- 尖端採短而鈍的教學安全造型；人物圖強調等待線、清空場地與成人指導。

## 後製

- 章節圖片由1536×1024 PNG轉為WebP，品質設定86。
- 社群圖由 Image 2.0 寬幅原稿縮放為1200×630 PNG。
- 網站文字、力向量、構造標籤與圖說以HTML／SVG呈現，不依賴生成圖內文字。
- 專案內轉檔用PNG複本已移除；Codex預設生成目錄仍保留原始檔。
