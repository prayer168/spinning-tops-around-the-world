## 人工覆核

- 首頁、科學、世界圖鑑的桌機及手機截圖均已檢視。
- 主視覺白字與琥珀字皆位於深松綠遮罩上，閱讀對比清楚。
- 文化圖像是教學示意，不宣稱為文物照片；國別名稱與玩法都連結至來源紀錄。
- 七面國旗依政府或官方機構資料繪製；歐洲旗幟明確標示為區域識別，不宣稱為單一國家國旗。
- 圖像中的手勢、繩索、尖端、空竹支撐方式與安全距離逐張檢查。
- 安全六步驟分鏡確認等待者在線後、投擲區淨空、繩圈整齊、尖端短鈍，且完全停穩後才回收。
