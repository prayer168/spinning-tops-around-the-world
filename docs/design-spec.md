# 教材藍圖

## 基本資料

- 中文名稱：旋轉世界：各國陀螺文化與科學
- 英文名稱：Spinning Tops Around the World
- Repository：spinning-tops-around-the-world
- 適用對象：國小五年級至國中低年級
- 領域：自然科學、生活科技、文化探索
- 學習時間：40～50 分鐘

## 學習目標

1. 指出陀螺的旋轉軸、重心、接觸點與本體。
2. 用角動量、力矩、進動與阻力解釋陀螺由穩定到倒下的過程。
3. 比較材料、質量分布、軸心與轉速對穩定性的影響。
4. 認識臺灣木陀螺的文化、操作與安全規則。
5. 依可靠來源比較不同地區陀螺的形制、啟動方式與玩法。

## 頁籤

1. 學習任務：主視覺、學習目標、核心焦點與開始按鈕。
2. 旋轉科學：六個核心概念、SVG 分解圖與三參數互動模擬。
3. 臺灣陀螺：傳統木陀螺、鞭陀螺、指尖陀螺、現代競技陀螺及玩法。
4. 世界圖鑑：七個地區的可點選圖鑑卡。
5. 操作安全：六步驟分鏡、排序活動與正誤對照。
6. 圖像挑戰：八題理解、應用、推理與圖像判讀。
7. 自主學習：八筆政府、博物館、大學與文化機構資源。

## 互動與動畫

- 模擬器：轉速、地面摩擦與重心高度滑桿；狀態、SVG 與文字同步。
- 動畫：播放、暫停、重播、速度、重設；支援降低動態偏好。
- 排序：點選與鍵盤皆可完成纏繩、握持、投擲、放手、回收流程。
- 圖鑑：按鈕展開完整資料，不以懸停作為唯一操作。
- 測驗：即時解析、計分、重新挑戰與回看教材。

## 課綱對應

- 核心素養：自然科學探究、科技資訊運用、文化理解與尊重。
- 學習表現、學習內容與正式代碼：待教師依正式課綱手冊確認。
- 評量以觀察、比較、推論、操作與真實安全情境為主。

## 預計檔案

HTML、分層 CSS、原生 JavaScript、內容／題庫／資源 JSON、18 張 Image 2.0 圖像、教師指南、來源、圖像紀錄與測試報告。
